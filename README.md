# BASADATA

Проект для работы с базой данных самолетов, предоставляющий функционал для фильтрации и анализа данных.

## Функционал

- Получение средней скорости самолетов
- Получение списка самолетов со скоростью выше средней
- Получение списка стран и количества самолетов в их воздушном пространстве
- Поиск самолетов по ключевым словам в позывных

## Установка

1. Клонируйте репозиторий:
git clone <URL_репозитория>

2. Установите зависимости с помощью Poetry:

poetry install


## Использование

1. Активируйте виртуальное окружение:
* poetry shell

2. Создать файл database.ini с необходимой информацией указанной в "database.ini.example" для работы с postgresql


3. В модуле "set_country.py" прописать страны необходимые для отслеживания в формате:
- переменная country = [ваши страны на английском языке через запятую с большой буквы]

4. Запустите основной файл:
python main.py

5. Следуйте подсказками

## Основные методы

### get_avg_speed()
Получает среднюю скорость самолетов из базы данных.

**Возвращает:**
- float: Средняя скорость всех самолетов

### get_aeroplanes_with_higher_speed()
Получает список самолетов со скоростью выше средней.

**Возвращает:**
- list: Список кортежей с информацией о самолетах выше средней скорости

### get_countries_and_aeroplanes_count()
Получает список стран и количество самолетов в их воздушных пространствах.

**Возвращает:**
- list: Список кортежей (страна, количество_самолетов)

### get_aeroplanes_with_keyword(symbol)
Получает список самолетов, в позывных которых содержатся указанные символы.

**Аргументы:**
- symbol (str): В формате соответствующие SQL

**Возвращает:**
- list: Список кортежей с информацией о найденных самолетах

## Требования

- Python 3.14
- PostgreSQL
- psycopg2
- Poetry
